# Quarp (Android)

Android wrapper for QUMS portal with on-device OCR

> [!CAUTION]
> This app is an unofficial wrapper and is not affiliated with or maintained by the institution providing the ERP. Use your own student account and follow your institution's policies when using the app.

## Getting Started

This project requires [Android Studio](https://developer.android.com/studio#android-studio-downloads), [Android SDK](https://developer.android.com/studio#command-line-tools-only), and [JDK](https://www.oracle.com/in/java/technologies/downloads/#java17).

### Build

Clone the repository and open it in Android Studio.

```bash
git clone https://github.com/qums-qa/android-app
cd android-app
```

Build and run the app from Android Studio.

## How It Works

The app loads the student ERP inside an Android `WebView`, so the dashboard can be accessed without opening a separate browser.

The app also keeps the WebView session and cookies, allowing the login session to persist between requests/app launches.
